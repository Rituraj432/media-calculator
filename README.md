# Neon Glow Mobile Calculator 🧮✨

A fast, ultra-responsive, and modern web-based calculator featuring a vibrant **neon glow dark theme**. Designed specifically for seamless mobile and desktop use with zero bloat.

---

### ✨ Features
* **Neon Aesthetic:** Sleek dark-mode interface with glowing button accents.
* **Mobile-First Design:** Fully responsive layout tailored for smooth touch controls and one-hand usage.
* **Instant & Lightweight:** Pure Vanilla JavaScript, HTML5, and CSS3—no heavy dependencies, frameworks, or external libraries.
* **Offline Ready:** Operates smoothly right inside the browser with minimal resource consumption.

---

### 🛠️ Built With
* **HTML5:** Clean structural layout.
 **JavaScript (ES6):** Fast expression parsing and real-time calculation logic.
