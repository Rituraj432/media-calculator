# 📱 Mobile-Calculator

## 🔥 Neon Glow Mobile Calculator 🧮✨

A fast, ultra-responsive, and modern web-based calculator featuring a vibrant neon glow dark theme. Designed specifically for seamless mobile and desktop use with zero bloat.

### ✨ Features

- **Neon Aesthetic:** Sleek dark-mode interface with glowing button accents. Cyan (#00f5ff) & Pink (#ff00ff) glow effect.
- **Mobile-First Design:** Fully responsive layout tailored for smooth touch controls and one-hand usage. Works on all devices.
- **Cartoon Animations:** Floating cartoons 🛸 UFO, 👨‍🚀 Astronaut, 🚀 Rocket, 🌙 Moon with smooth floating animation.
- **Instant & Lightweight:** Pure Vanilla JavaScript, HTML5, and CSS3 — no heavy dependencies, frameworks, or external libraries.
- **Smart Calculations:** 
    - Addition (+), Subtraction (-), Multiplication (×), Division (÷)
    - Percentage (%) with direct % display like 83.33%
    - Handles large numbers without e+ error
- **Extra Functions:** Clear All (AC), Delete (DEL), Decimal support.
- **Offline Ready:** Operates smoothly right inside the browser with minimal resource consumption. PWA supported.
- **Fast & Secure:** Single HTML file, super fast loading with .nojekyll and manifest.json.

---

### 🛠️ Built With

- **HTML5:** Clean structural layout, Semantic tags.
- **CSS3:** Backdrop blur, Neon shadows, Grid layout, Keyframe animations.
- **JavaScript (ES6):** Fast expression parsing, real-time calculation logic, Error handling for Infinity.
- **PWA:** manifest.json + pwabuilder-sw.js for offline support.
